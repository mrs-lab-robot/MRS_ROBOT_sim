# Arena documentation

This directory contains short development notes for the Arena integration. The project is under active development and is not a stable release.

- [Data capture](data_collection.md): current experimental recording boundary and limitations.
- [Teleoperation architecture](teleoperation_architecture.md): process separation and simulation-side safety boundary.
- [Evaluation](arena_ppo_evaluation.md): current evaluation entrypoint and its non-benchmark status.

The desktop workflow and real-robot application live in a separate companion repository; they are not documented as part of this simulation repository.
