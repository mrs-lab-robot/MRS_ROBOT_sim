# MRS_ROBOT 项目架构

```
MRS_ROBOT/                                      # 真机与应用仓库（当前工作区根目录）
├── openflex_ws/src/                            # 真机 ROS 2 工作空间源码
│   ├── openflex_integrated/                      # 上位机、整机描述与一体化启动包
│   │   ├── openflex_gui/openflex_gui/            # PySide6 控制中心及分页面实现
│   │   │   ├── main_window.py                   # 控制台装配、模式切换与任务协调
│   │   │   ├── pages/                           # 控制、传感器、采集、数据、训练、推理、电机、部署页面
│   │   │   ├── arena_control_panel.py            # Arena 仿真与 VR 采集控制面板
│   │   │   ├── arena_runtime.py                  # Arena Kit 与 ROS 桥进程管理
│   │   │   └── simulation_tasks.py               # 仿真及配套进程启动、停止与日志管理
│   │   ├── openflex_manager/                     # 机器人控制器、电机管理和硬件状态工具
│   │   ├── openarmx_integrated_description/      # 底盘、升降、双臂整机描述
│   │   └── openarmx_integrated_bringup/          # 真机整机及 VR 控制启动
│   ├── openflex_armx/                            # 双臂、夹爪描述与驱动控制
│   ├── openflex_chassis/                         # 底盘驱动、定位、建图与导航
│   ├── openflex_head/                            # 头部执行器与传感器
│   ├── openflex_lift_slide/                      # 升降机构描述、驱动与控制
│   ├── openflex_tactile/                         # 触觉传感器驱动与消息
│   ├── openflex_vr_bridge/                       # VR 控制器接入与 ROS 指令桥接
│   └── openflex_vla/                             # LeRobot 主从端、数据采集及 VLA 接口
│       ├── lerobot_robot_openflex_follower_ros2/   # LeRobot 真机接口、相机与触觉观测
│       ├── lerobot_teleoperator_openflex_leader_ros2/  # LeRobot 主端遥操作接口
│       ├── openarmx_lerobot/                     # 相机转发和 VLA/VR ROS 启动配置
│       ├── lerobot_scripts/                      # 数据采集、回放、训练推理入口
│       └── config/                               # 相机、触觉与观测/动作格式配置
├── openflex_drivers/                             # 真机驱动安装包与硬件配置
└── openflex_vr_apk/                              # Quest/Pico VR 控制端应用

MRS_ROBOT_sim/                                    # 仿真仓库（GitHub: mrs-lab-robot/MRS_ROBOT_sim）
├── sim_runtime/                                  # 【🔵 底层】仿真运行时：USD资产 / 传感器 / ROS 2 / 遥操作
│   ├── assets/                                   # 仿真资产：robots(USD权威)/environments/sensors/textures
│   ├── components/                               # 仿真组件：controllers/sensors/utils
│   ├── config/                                   # 运行时配置：physics/rendering/scenes/sensors
│   ├── ros2/openflex_isaac_sim/                  # 6 个 ROS 2 功能包（描述/合同/控制器/传感器/桥接/启动）
│   ├── ros2/mrs_robot_arena_bridge/              # Arena ROS VR 桥接包
│   ├── scenarios/                                # 独立相机、雷达等复现场景
│   ├── sensors/mid360/                           # MID360 仿真点云语义处理
│   └── teleoperation/                            # 通用遥操作 Python 包
├── isaaclab_ext/                                 # 【🟡 中层】Isaac Lab 扩展（mrs_robot_lab）
│   ├── src/mrs_robot_lab/                        # Articulation / Action / Observation 适配层
│   ├── scripts/                                  # 关节控制、相机、smoke、PPO 训练等脚本
│   └── tests/                                    # Isaac Lab 层单元测试
├── arena_benchmark/                              # 【🟢 顶层】Arena Benchmark（mrs_arena）
│   ├── src/mrs_arena/                            # Embodiment / Scene / Task / 评测扩展
│   ├── src/mrs_robot_arena/                      # OpenFleX 机器人 Arena 实现
│   │   ├── assets/resolver.py                    #   权威 USD 与接口配置解析
│   │   ├── contracts.py                          #   动作/观测接口校验
│   │   ├── embodiments/                          #   机器人、动作项、底盘模型
│   │   ├── environments/                         #   环境与场景
│   │   ├── teleoperation/                        #   VR 协议、动作映射、Kit 面板
│   │   ├── recording/                            #   Episode 采集、HDF5、LeRobot 导出
│   │   └── runners/                              #   键盘/VR 遥操作运行器
│   ├── configs/                                  # benchmark/environments/experiments/runtime 配置
│   ├── integrations/ros2/                        # ROS VR 数据 ↔ Arena UDP 桥
│   ├── scripts/                                  # 冒烟测试、遥操作、评估、数据导出
│   ├── tests/                                    # unit / integration / acceptance 三层测试
│   └── docs/                                     # 遥操作、采集、PPO 评估文档
├── third_party/IsaacLab-Arena/                   # 上游 Arena 子模块（只读，固定版本）
├── configs/versions.yaml                         # 全局版本锁：Isaac Sim / Lab / Arena
├── config/dependencies.repos                    # ROS 第三方依赖版本
├── tools/                                        # 资产工具：calibrator / data_collector / model_converter
├── test/                                         # 历史测试：sim单元 / ROS集成 / 性能 / 端到端
├── tests/                                        # 新分层测试：migration / sim_runtime
├── reports/                                      # 迁移、运行、性能验证记录
└── docs/                                         # 架构、部署、运行、报告规范
```

> **依赖方向**：`sim_runtime → isaaclab_ext → arena_benchmark`，下层不依赖上层。
> ROS 2（Humble / Python 3.10）与 Arena（Isaac Sim 6 / Python 3.12）环境隔离。
